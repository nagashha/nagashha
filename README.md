### Selected work

**[atac-seq-b-cell-differentiation](https://github.com/nagashha/atac-seq-b-cell-differentiation)** — chromatin accessibility across B-cell differentiation, from raw reads to transcription-factor motif enrichment. 14,662 differentially accessible regions between bulk B cells and plasmablasts, and an ETS-to-IRF regulatory shift that appears in the motif enrichment and in the target-gene selection independently.

The pipeline is standard; what the project is really about is the places where checking the data changed what I ran. A week-1 sample that turned out to be an NK cell rather than a B cell. A paired statistical design the sample set could not support. Two project documents specifying different filter thresholds, which I settled by running both to the end and measuring the difference rather than by picking one.
